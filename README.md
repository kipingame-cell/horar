# ✳ Хорар

Офлайн-инструмент для построения хорарных карт. Астрономические расчёты отделены от символических трактовок; каждый вывод связан с вычисленными показателями. Без ИИ, аккаунта, рекламы и передачи вопросов на сервер. Развёрнутый сайт доступен владельцу; исходники и APK открыты.

## Обновление 1.1

Восемь подробных шагов разбора каждой карты: факт расчёта, символическое значение, ограничение вывода. Словарь 20 терминов с поиском. Пояснения включаются и в текстовый экспорт. Исправлены классификация аспекта непосредственно перед точностью и рецепции одного сигнификатора к самому себе. Импорт проверяет структуру, сохраняет исходы и исключает дубли карт даже при разных ID.

## Возможности

- Семь классических планет, тропический зодиак, геоцентрические долготы, ретроградность.
- Геометрический расчёт домов Региомонтана; равнодомная и цельнознаковая системы.
- Мажорные аспекты со схождением/расхождением, таблицы планет и куспидов.
- Управители вопроса, достоинства и рецепции: обитель, экзальтация, триплицитет, египетские термы, фасы, изгнание и падение.
- Точные будущие аспекты Луны до следующей смены знака, вычисляемые численным поиском.
- Предостережения о раннем/позднем ASC, Сатурне в VII доме, сожжении и казими.
- Журнал вопросов, исходы, защита от повторного сохранения, импорт/экспорт JSON и текстового разбора.
- Поддержка Android 8+ с актуальным Android System WebView, безопасные системные диалоги открытия и сохранения файлов.

## Запуск и сборка

Сайт: каталог `dist/` — готовая статическая сборка. Разместите на HTTPS-хостинге. После первого открытия доступны офлайн-ресурсы через Service Worker.

Проверки: `npm test` (Node 22+), без установки npm-зависимостей.

Android: JDK 17, Gradle 8.13, Android SDK 35. Выполните `npm run build`, затем `gradle assembleRelease`. Результат: `app/build/outputs/apk/release/app-release-unsigned.apk`.

GitHub Actions проверяет вычисления, синхронизирует веб-ресурсы, собирает APK и запускает Android Lint, затем устанавливает APK на эмулятор Android 15 (1080×2400). Публикация APK, ZIP сайта, контрольных сумм и архива доказательств тестирования выполняется только после успешного UI-прогона. APK имеет тестовую подпись Android. Для магазина нужна отдельная стабильная release-подпись.

## Метод и ограничения

Astronomy Engine **2.1.19** (MIT, Don Cross), включён локально: `dist/vendor/astronomy.js`. Геоцентрический вектор переводится из EQJ в истинную эклиптику даты. Дома Региомонтана — пересечения эклиптики с плоскостями через точки равноделённого экватора и север/юг горизонта.

Диапазон интерфейса: 1900–2100 годы, широты ±65°. Часовой пояс городов берётся через Intl; смещение UTC доступно для ручной проверки неоднозначных местных часов при переходе DST.

Мажорные аспекты 0/60/90/120/180°. Орбисы: 8° для светил и 6° для остальных пар. Схождение — уменьшение орбиса по текущим скоростям (центральная разность ±1 минута); точный аспект и практически нулевая относительная скорость выделяются отдельно. Оно не гарантирует совершенствования аспекта. Луна без курса — отсутствие точных мажорных аспектов с классическими планетами до выхода из знака.

**Не включены в итоговое суждение:** передача/собирание света, запрет, рефранация, термы, фасы, триплицитеты, производные дома и сроки событий. Это объяснимый базовый разбор, не полный автоматический астролог и не гарантированный ответ «да/нет».

Астрологическая интерпретация не является научно подтверждённым прогнозом. Приложение не генерирует проценты вероятности.

## Данные

Журнал хранится локально. Между браузером и APK автоматической синхронизации нет — используйте JSON. Экспортируйте журнал перед очисткой данных или переустановкой APK. Android-приложение не запрашивает INTERNET, геолокацию или общий доступ к накопителю.

## Структура

- `dist/engine.js` — расчёты и правила;
- `dist/app.js`, `dist/index.html`, `dist/style.css` — интерфейс и локальный журнал;
- `app/` — Android WebView с локальными ресурсами и системными файловыми диалогами;
- `tests/` — численные тесты и независимые эталонные данные;
- `.github/workflows/release.yml` — сборка и публикация;
- `docs/` — метод, верификация и заметки выпуска.


## Расширенный анализ 1.5

В новом расчёте текст вопроса предлагает тему и роль человека. Поддержаны отношения и примирение, получение должности, зарплата (II от X = XI), собственные деньги, потерянные вещи, недвижимость, вуз, поездки, сообщения, творчество, друзья и повседневные задачи. Для супруга, друга, брата/сестры и ребёнка можно выбрать роль явно; предмет считается производным домом. Распознавание локальное, по правилам, без передачи вопроса внешнему ИИ. В неоднозначном случае выбирайте дом вручную.

- 7 предварительных проверок, отдельные состояния сигнификаторов и направленные рецепции.
- Реальные будущие мажорные аспекты в окне 30/90 дней; шаг 6 часов, уточнение корней до 0,5 секунды. Аспекты ищутся и за пределами текущего орбиса.
- Смена знака и станция до контакта блокируют вывод об осуществлении в прежних условиях. Само отсутствие контакта не превращается в категорическое «нет».
- Ограниченные правила передачи/собирания света; промежуточный контакт отображается как возможное вмешательство, а не доказанный запрет.
- Последний аспект Луны за 4 дня и следующие контакты, Луна без курса до действительного входа в следующий знак.
- Один итог и основания для новичка, профи и PDF. Ссылки и журнал сохраняют версию правил, роль, режим темы и окно поиска; старые записи остаются воспроизводимыми по прежним правилам.

Методика и ограничения: [docs/ANALYSIS.md](docs/ANALYSIS.md). Проверки: `npm test`; подготовка одинаковых веб-ресурсов для Android: `npm run build`. CI собирает release, проверяет Android Lint и выполняет инструментальные тесты на Android 15. Артефакт CI остаётся **неподписанным**, пока не применён исходный release-ключ; новый ключ для обновлений не создаётся.
