# Проверки 18 октября 2026

`npm test`: 7 тестовых групп успешно.

Независимый численный эталон: Swiss Ephemeris 2.10.03 / Moshier, pyswisseph 2.10.3.2. Библиотека использована только для верификации, не включена в приложение. Данные в tests/reference.json.

Проверены 5 карт: Москва (2026), экватор (2000), Сидней (1990), 64° северной широты (2050), Нью-Йорк (1900).

Максимальная разница на этих примерах:
- Куспиды Региомонтана: 0.000526° (около 1.9 угловой секунды).
- Долготы классических планет: 0.005607° (около 20.2 угловой секунды).

Это выборочная верификация, а не доказательство предельной точности на всём диапазоне дат.

Проверены циклический порядок домов на широтах −65, −40, 0, 40, 65°, оппозиция куспидов, границы домов через 0°, равнодомная/цельнознаковая системы, валидация входных данных, ретроградность, точность найденных аспектов Луны и момент смены знака.

Ограничения проверки: локальная инфраструктура браузерного предпросмотра недоступна; пользовательский визуальный прогон сайта не выполнен. Android APK собирается и проходит Lint в GitHub Actions. На физическом устройстве не проверено. Результаты CI проверяйте по конкретному запуску.

## Обновление 1.1

Локально успешно: 17 групп Node-тестов. Добавлены проверки непосредственно до/после совершенствования аспекта, перехода через 0° и 180°, ретроградного движения, одинакового сигнификатора, структуры пояснений, кругового переноса журнала, повторного импорта и повреждённых данных.

CI дополнен `UiSmokeTest` на установленном APK в эмуляторе Android 15, 1080×2400. Публикация релиза зависит от маркера HORAR_SMOKE_OK. Сценарий проверяет ввод через нативную клавиатуру, карту, 8 объяснений, преобразование UTC, Луну, отсутствие дублей, сохранение исхода, сохранность после перезагрузки, восстановление карты, текстовый отчёт, JSON-перенос, защиту от некорректного JSON, поиск словаря, поворот экрана и обязательность вопроса. Скриншоты сохраняются в архив доказательств релиза.

Локальный браузерный визуальный прогон сайта всё ещё недоступен; сайт и APK используют одинаковые веб-файлы. Системные диалоги выбора/сохранения файла и физические устройства не покрыты этим сценарием.
