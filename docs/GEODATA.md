# Офлайн-справочник 1.2

Источник: https://download.geonames.org/export/dump/ (GeoNames).
Данные: RU.zip, cities500.zip, admin1CodesASCII.txt. Лицензия CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

Изменения относительно исходника: оставлены населённые пункты с часовым поясом, исключены разрушенные/исторические/заброшенные записи (PPLQ/PPLH/PPLW), объединены по geonameid. Выделены кириллические названия, сохранены латинские и кириллические варианты, координаты, население, регион и IANA timezone. Названия регионов сохранены из GeoNames admin1CodesASCII, без догадок о переводе. Данные отсортированы по населению и упакованы в gzip-части по 10 000 записей.

423 050 уникальных записей, из них 192 137 в России. Исходные SHA256 и дата преобразования записаны в dist/data/places-meta.json. Пределы полноты соответствуют исходным данным, а не обещанию охватить все населённые пункты мира.

Воспроизведение: `python scripts/build-places.py /path/to/downloaded/geonames`.
Поиск выполняется в Web Worker, без внешних запросов. Проверяются нормализация ё/е, латиница, одноимённые места, пустая выдача, UTC в зимний/летний период, повторяющиеся и отсутствующие часы и перенос места в журнал.
